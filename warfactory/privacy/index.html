WARFACTORY 모바일 앱 개인정보처리방침

(주)장원커뮤니케이션은 WARFACTORY 모바일 앱 이용자의 개인정보를 보호하기 위해 다음과 같이 처리합니다. 이 문서는 Android와 iPhone 앱에 적용합니다.

1. 게임 기록과 설정

회원가입 없이 게임을 이용할 수 있습니다. 게임을 이어서 진행하고 설정을 유지하기 위해 작전 진행 상태, 전투 기록과 소리 설정 등을 기기의 앱 저장소에 보관합니다. 전투 기록에는 작전과 승패, 시작·종료 시각, 소요 시간 등이 포함될 수 있습니다.

현재 공개된 Android 1.2.0의 자체 플레이 분석 기록은 회사 서버로 전송되지 않습니다. 외부 SDK의 처리 가능성은 아래에서 별도로 설명합니다.

분석을 지원하는 버전의 플레이 기록

아래 내용은 플레이 분석 기능을 지원하는 앱 버전에 적용됩니다. 현재 공개된 Android 1.2.0에는 적용되지 않으며, 실제 수집 시작 여부는 해당 기능의 출시와 이용자의 동의에 따라 달라집니다.

회사는 게임 오류를 파악하고 작전 진행과 난이도를 개선하기 위해 만 14세 이상임을 직접 확인하고 동의한 이용자의 최소 플레이 기록을 수집합니다. 개인정보 수집·이용과 국외 이전에 대한 선택 동의는 각각 별도로 받으며, 어느 동의에도 응하지 않아도 게임을 이용할 수 있습니다.

수집 항목은 앱에서 무작위로 생성한 이용·접속·전투 시도·이벤트 식별자, 동의 문구 버전, 앱 버전, Android 또는 iOS 여부와 화면 크기 분류, 작전 번호와 이벤트 발생 시각, 게임 화면 상태, 전투 시작·승리·패배·이탈·재시도 및 소요 시간, 지정된 기능 사용과 오류 발생 여부입니다. 식별자는 이름이 없어도 기록을 서로 연결할 수 있습니다. 분석 기록에 이름, 이메일, 생년월일, 광고 식별자, 자유 입력 내용이나 오류 상세 메시지는 포함하지 않습니다.

분석 처리를 맡는 Cloudflare, Inc.는 전 세계 여러 지역의 네트워크에서 요청을 처리할 수 있고, 분석 데이터는 미국 관할 Cloudflare D1 데이터베이스에 저장합니다. 수집과 국외 이전에 동의한 뒤 플레이 기록이 발생하면 HTTPS로 전송·이전됩니다. Cloudflare의 개인정보 문의처는 privacyquestions@cloudflare.com입니다. 네트워크 제공자의 보안 처리 과정에서는 IP 주소 등이 처리될 수 있습니다. 자세한 내용은 Cloudflare 개인정보처리방침을 확인해 주세요.

분석 이벤트는 서버 수신 시점부터 90일이 지나면 매일 실행되는 정리 작업으로 활성 저장소에서 삭제합니다. 정리 작업이 정상 실행되면 만료 후 최대 하루가 더 걸릴 수 있고, 장애가 발생하면 지연될 수 있습니다. Cloudflare D1 무료 플랜에서는 삭제 이전 복구 이력에 기록이 최대 7일 더 남을 수 있습니다.

분석 동의를 철회하면 이후 수집과 대기 중인 전송을 중지하지만 이미 서버에 보낸 기록은 자동 삭제되지 않습니다. 철회 전에 전송된 요청이 이미 처리 중이면 철회 시점 전후에 서버에 도착할 수 있습니다. 앱에서 별도로 삭제를 요청하고 요청이 성공하면 해당 앱 설치에 연결된 분석 기록을 활성 저장소에서 삭제합니다. 기기에 저장된 게임 진행 기록은 이 분석 기록과 별개이며, 복구 이력에는 위 기간 동안 삭제 전 기록이 남을 수 있습니다.

삭제 기록이 재전송으로 되살아나는 것을 막기 위해 무작위 식별자와 삭제 비밀값의 해시를 삭제 후 38일간 보관한 뒤 일일 정리합니다. 삭제 재요청 또는 복구 작업 시 기간이 연장될 수 있습니다. 삭제 비밀값은 기기에서 생성하며 서버에는 원문 대신 해시를 저장합니다.

앱 제거 또는 앱 데이터 삭제로 기기의 식별자나 삭제 비밀값을 잃으면 이전 기록을 확인하거나 앱에서 삭제를 요청하는 데 제한이 있을 수 있습니다. 앱 제거만으로 서버 기록이 자동 삭제되지는 않습니다. 권리 행사에 관한 문의는 아래 연락처로 보내 주세요. 삭제 비밀값이나 인증번호는 이메일로 보내지 마세요.

2. Android 외부 SDK

Android 1.2.0에는 Google Play 결제와 Google 계정 관련 라이브러리가 포함됩니다. 현재 이 앱은 결제, 계정 로그인 및 보상형 광고 기능을 제공하지 않으며, Google 광고 SDK는 이 버전에 포함되어 있지 않습니다.

이전 Android 1.1.0 내부 테스트 버전에는 Google Mobile Ads SDK와 광고 개인정보 선택을 관리하는 Google UMP가 포함되어 있습니다. Google의 SDK 안내에 따르면 광고 SDK가 동작할 때 IP 주소와 대략적인 위치, 앱 상호작용, 진단 정보, 기기·계정 식별자가 광고, 분석과 부정 사용 방지를 위해 처리될 수 있습니다. 자세한 내용은 Google의 SDK 데이터 안내를 확인해 주세요.

Google 서비스의 개인정보 처리와 보관에 관한 내용은 Google 개인정보처리방침과 정보 보관 안내를 확인해 주세요.

3. iPhone 외부 SDK

iPhone 앱은 게임 화면을 표시하기 위해 Capacitor와 Cordova를 사용합니다. 두 SDK의 개인정보 매니페스트는 추적과 수집 항목이 없다고 선언합니다.

4. 문의

이용자가 이메일로 문의하면 발신 이메일 주소, 문의 내용과 이용자가 첨부한 자료를 문의 접수와 회신을 위해 처리합니다. 비밀번호나 인증번호 등 불필요한 민감정보는 보내지 마세요.

문의 메일은 Google Gmail을 통해 수신합니다. Google은 세계 여러 지역의 서버에서 정보를 처리할 수 있습니다. Google 서비스의 처리와 보관은 Google 개인정보처리방침 및 계정 설정에 영향을 받습니다.

문의 메일과 첨부자료는 문의 처리가 완료되면 지체 없이 삭제합니다. Gmail에서 삭제한 메일은 휴지통에 최대 30일 동안 남을 수 있으며, 이후 자동 삭제됩니다. 법령에 따라 보존이 필요한 경우에는 해당 보존 기준을 확인해 적용합니다.

지원·정책 웹페이지

공개 지원 페이지와 개인정보처리방침 페이지는 GitHub Pages를 이용합니다. GitHub의 안내에 따르면 이 페이지를 방문할 때 GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 처리와 보관에 관한 내용은 GitHub 개인정보처리방침을 확인해 주세요.

5. 저장 정보의 삭제와 이용자의 권리

기기에 저장된 게임 기록은 기기의 앱 데이터 삭제 또는 앱 제거 기능으로 삭제할 수 있습니다. 기기와 계정의 설정에 따라 앱 데이터가 운영체제 백업에 남거나 복원될 수 있으므로, 필요한 경우 백업 서비스의 삭제 방법도 확인해 주세요.

이용자 또는 만 14세 미만 이용자의 법정대리인은 개인정보의 열람, 정정, 삭제 또는 처리정지 등을 아래 문의처로 요청할 수 있습니다. 법령상 확인이나 제한이 필요한 경우 이를 반영해 처리합니다.
